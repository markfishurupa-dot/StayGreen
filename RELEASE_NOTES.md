# StayGreen v1.1 — Windows portable release

StayGreen is a compact Windows system-tray utility that sends a brief Ctrl + Shift pulse at configurable intervals and requests Windows to prevent idle system/display sleep while active.

### Features

- No installation or administrator privileges required in normal Windows user environments.
- Successful real-world testing for over six months across multiple Windows computers.
- Tested with popular workplace messaging and collaboration apps, with active/available presence observed in those environments.
- No Microsoft Defender alerts or interference observed during testing.
- Right-click system tray menu: status, last/next pulse, pause/resume, pulse now, interval, open folder, exit.
- Pulse frequencies: 1, 2, 4, 5, 10, and 15 minutes; 4 minutes by default.
- No network features, telemetry, or installer in the supplied code.

### What's new in v1.1

- Updated the application name and branding to **StayGreen**.
- Introduced the new icon for the executable and system tray.
- Preserved the existing timer and keyboard-pulse behavior.

### Download

Download **`StayGreen.exe`** below, save it anywhere, and double-click to start. Look for the icon in the Windows system tray; right-click for controls.

**System requirements:** Windows with appropriate .NET Framework components. The normal launch does not require administrator rights.

**Note:** Antivirus and reputation checks can vary with machine policy and binary distribution. Messaging presence may behave differently across apps and environments. No claim of universal compatibility is intended.
